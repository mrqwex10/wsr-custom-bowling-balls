# Building from source

Everything (textures, animations, the PowerPC patch, the Riivolution XML) is generated by the scripts in `scripts/`
from your **own** copy of Wii Sports Resort (USA, RZTE01 Rev 1).

## 1. Tools

- Python 3.10+ with a virtual environment in `tools/venv`:
  ```
  python3 -m venv tools/venv
  tools/venv/bin/pip install pillow numpy scipy capstone unicorn
  ```
- [Wiimms ISO Tools](https://wit.wiimm.de/) (`wit`) and [Wiimms SZS Tools](https://szs.wiimm.de/) (`wszst`, `wimgt`),
  linked into `tools/bin/`.

## 2. Game files

Extract the Bowling archive and the main executable from your disc image:

```
tools/bin/wit extract YOUR_GAME.wbfs work/disc --files "+/files/Common/BwlScene/common.carc" --files "+/sys/main.dol" --psel data
```

## 3. Render the artwork

```
P=tools/venv/bin/python
$P scripts/make_holo_anim.py 2 designs/holo_anim
$P scripts/make_pool.py
for n in 16 8 6; do $P scripts/make_orbs.py holo,venom,inferno,blackhole,arcane,dragoneye $n; done
for n in 16 10 8; do $P scripts/make_orbs.py gold,diamond $n; done
```

## 4. Build and test

```
$P scripts/build4.py          # -> output/riivolution/WSR_ball_mod.xml + output/WSR_ball_mod/*/common.carc
$P scripts/test_hook.py       # runs the patched GXLoadTexObj from main.dol in a PowerPC emulator
$P scripts/verify4.py         # end-to-end: decodes what the GPU would receive for every ball slot
```

Copy `output/riivolution` and `output/WSR_ball_mod` to your SD card (or use `scripts/install_sd.sh`).

## Layout

| File | What it does |
|---|---|
| `hook.py`, `ppcasm.py` | The GXLoadTexObj patch, written with a tiny PowerPC assembler |
| `make_orbs.py`, `make_holo*.py` | Animated orbs and the Gold / Diamond balls (looping frames + baked relief) |
| `make_pool.py`, `make_identity.py` | Regular ball designs |
| `build4.py` (+ `build*.py`) | Packs textures into the archive, writes tags and the Riivolution XML |
| `test_hook.py`, `verify4.py` | Emulator tests |
